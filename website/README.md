# AIHostCheck website

Promotional and project-status website for [AIHostCheck](https://github.com/raydthanh/aihostcheck).

The public AIHostCheck repository remains the source of truth for product code, releases, report schemas, documentation, privacy, and security policy. This website reads public repository and release metadata from GitHub with a cached, verified fallback.

## Local development

```sh
npm install
npm run dev
```

## Verification

```sh
npm run typecheck
npm run build
```

The intended production domain is `aihostcheck.bond` on Vercel.
